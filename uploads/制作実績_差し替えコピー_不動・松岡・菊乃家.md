# 制作実績セクション｜差し替えコピー（不動開発建設・松岡製作所・菊乃家）

使い方：クロードデザインのチャット欄に、カードごとに「事例◯のカードをこの文言に差し替えて」と指定して以下のコードブロックを貼る。
※3枚目（宿泊施設＝GR）は菊乃家仕様に全差し替え。画像は宮島の鳥居のままで合う。

## 事例1｜不動開発建設（1枚目・現行カードの強化版）

タグ：`SNS・動画`

```
ご依頼：「Instagramを始めたい」（不動産・住宅建設）

私たちの判断：商材の見せ方を踏まえ、YouTubeチャンネル「ルームツアー動画」を軸に提案。
Instagram・LP・Web広告は、YouTubeを起点とした導線として再設計。

結果：初投稿動画が1週間で1.8万再生。3カ月で収益化要件を満たすチャンネルに成長。
視聴者から複数県にわたる住宅の受注が発生。現在は動画・Instagram・LP・
Google広告（年末キャンペーンで高CTR）までを一貫して運用中。

── 媒体を引き直したら、最初の一本から跳ねた。
```

## 事例2｜松岡製作所（2枚目・具体化版）

タグ：`SNS内製化→委託・海外展開`

```
ご依頼：「内製化していたSNSを委託したい」（創業約100年のキッチンメーカー）

私たちの判断：コンセプトから作り直し、世界観に統一感を持ったInstagramへ刷新。
100点以上の商品撮影から素材を整備し、リール・YouTubeなど動画コンテンツも開始。
さらに海外展示会への出展に合わせ、ドイツ版Instagramの運用とグローバル向けの
見せ方までトータルで設計。

結果：SNSからのショールーム来客が増加。SNS運用にとどまらず、LP制作・
ショールームイベントの企画運営まで、マーケティング全体のパートナーに。

── 商品の魅力は、伝え方で得をする。
```

## 事例3｜菊乃家（3枚目・GR事例からの全差し替え）

タグ：`SNS運用・予約導線`

```
ご依頼：「Instagramで集客につなげたい」（宮島の宿泊施設）

私たちの判断：広告費を積む前に、アカウントの世界観とコンテンツ戦略から設計し直し。
写真撮影・プロモーション動画からInstagram→公式予約への導線までを一体で構築。

結果：フォロワーは9.5カ月で1,070→1,919人（+849人）。1投稿あたりの
フォロワー獲得は1.52→9.13人と約6倍に。年間成長ペースは153→1,071人。
これを累計広告費 約2万円で実現。保存数の増加でリピート宿泊候補も拡大。

── 広告費ではなく、設計で伸ばす。
```
