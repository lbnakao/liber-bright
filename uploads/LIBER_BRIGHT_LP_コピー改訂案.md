# LIBER BRIGHT LP ｜ 差し替えコピー案（リベルブライトらしさ強化版）

狙い：「上質・誠実・伴走」の土台はそのままに、**「媒体ありきで考えない」という一点の主張**と、**それを証明する実績ストーリー**を背骨として通す。相手を「地方企業」とラベリングする表現は外し、相手の“売りたい・伸ばしたい”を主語にする。

声のトーン：温かいが、芯がある。「相談しやすい」＋「ここは他と違う（常識を疑い、はっきり提案する）」の両立。明朝＋上品なセリフ、文字間ゆったり。

---

## 1. ファーストビュー（差し替え）

**メインコピー（2行・自然な改行位置）**

```
「売りたい」を、
戦略から動かす。
```

**サブコピー**

```
言われたモノを作る制作会社ではありません。
「どう売るか・どう集客するか」の戦略設計から、
制作・運用までをワンストップで担う、課題解決型のクリエイティブエージェンシー。
```

**ボタン**

```
無料相談はこちら ／ サービスを見る
```

> 別案（お好みで）
> ・メイン：その商品の魅力を、ちゃんと届ける。／ サブ：集客を、戦略から。
> ・メイン：本気で集客を変えたい企業へ。／ サブ：戦略から、制作・運用まで。

## 2. 新セクション「媒体ありきで考えない」（FV直下、またはサービスの前に挿入）

このLPで一番“リベルブライトらしさ”が立つ核のブロック。

**見出し**

```
その施策、本当に最適ですか。
```

**リード文**

```
「Instagramをやりたい」「広告を打ちたい」——
ご相談は、いつも“手段”から始まります。
私たちはまず、その手段が本当にゴールへの最短路かを問い直します。
商品の強み、届けたい相手、勝てる土俵を見極めてから、最適な媒体を選び直す。
だから時には、ご依頼とは違う打ち手をご提案することもあります。
```

**3ステップ（横並びカード／ネイビー細線アイコン）**

```
01  課題を聞き切る   ── 「やりたいこと」の奥にある“本当のゴール”まで掘り下げる
02  打ち手を選び直す ── 媒体ありきで考えず、勝てる手段を再設計する
03  最後までやり切る ── 企画から制作・運用まで、一気通貫で伴走する
```

## 3. 制作実績（ストーリー型に作り替え）

各カードを「ご依頼 → 私たちの判断 → 結果」の3段＋一言キャッチで構成。
※社名は許諾が取れたものだけ表に出し、未許諾は業種表記のままでOK。

**事例1｜SNS・動画**

```
ご依頼：「Instagramを始めたい」（不動産開発・建設）
私たちの判断：商材の見せ方を踏まえ、YouTubeを提案。
結果：立ち上げ直後からバズを獲得。
── 媒体を引き直したら、最初の一本から跳ねた。
```

**事例2｜海外展開・ブランディング**

```
ご依頼：「ステンレスシンクを海外で売りたい」（製造業）
私たちの判断：海外向けSNS展開とグローバルLPをセットで提案。世界観の構築から撮影手配までトータルで。
結果：海外で通用する“見せ方”を一気通貫で設計。
── “売りたい”の解像度を上げると、打ち手は変わる。
```

**事例3｜企画・集客導線**

```
ご依頼：「集客のための広告を打ちたい」（宿泊施設）
私たちの判断：広告の前に、フックとなる“新しい宿泊プラン”そのものを企画。
結果：広告単体ではなく、集客の導線まるごとを構築。
── 広告を回す前に、回す価値があるものをつくる。
```

## 4. ついでに直したい既存文言（任意）

- 強み「地方中小企業に寄り添う提案力」→ **「依頼を鵜呑みにしない提案力」** または **「事業の現場に踏み込む提案力」**
- 仕上がりイメージや見出しでの「地方企業」ラベルは外す。「地方対応可否」はFAQ（“地方でも対応できますか？”）に残すと自然。
- 会社の立ち位置として「広島・地域に根ざしたエージェンシー」とフッターで言うのは好印象なのでOK。
